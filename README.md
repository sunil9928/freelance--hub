# FreelanceHub

A modern freelance marketplace website built with React and Vite.

## Live Website

https://sunil9928.github.io/freelance--hub/

## Features

- Find Talent
- Find Projects
- Grow Your Career
- Freelance Job Listings
- Job Application Form
- Responsive Design
- Modern UI
- GitHub Pages Deployment

## Tech Stack

- React
- JavaScript
- CSS
- Vite
- GitHub Pages

## About

FreelanceHub is a frontend freelance marketplace project designed to connect clients with skilled freelancers and help freelancers discover new project opportunities.
