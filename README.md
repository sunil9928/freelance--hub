## 🧩 Core Experience

FreelanceHub is designed around a simple marketplace flow:

```text
Client
  ↓
Find Talent
  ↓
Explore freelancers / services

Freelancer
  ↓
Find Projects
  ↓
Explore jobs
  ↓
Apply
```

The project focuses on frontend interaction, responsive layouts, reusable React components, and a clean marketplace-style user experience.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/sunil9928/freelance--hub.git
cd freelance--hub
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

### Production build

```bash
npm run build
```

### Lint

```bash
npm run lint
```

### Preview production build

```bash
npm run preview
```
